# MentorIA
O MentorIA é uma plataforma inteligente de apoio acadêmico criada para ajudar estudantes da rede pública a organizarem seus estudos e se adaptarem à rotina escolar. O projeto busca transformar o celular em uma ferramenta produtiva, oferecendo recursos simples e acessíveis para planejamento, acompanhamento de tarefas, metas e lembretes acadêmicos. 

## Objetivo
Auxiliar estudantes do ensino médio a desenvolverem hábitos de estudo mais organizados, reduzindo a procrastinação e melhorando o acompanhamento das atividades escolares por meio da tecnologia. 

## Público-Alvo
O foco inicial do projeto são estudantes do 1º ano do ensino médio da rede pública do Piauí, especialmente alunos que enfrentam dificuldades de organização, adaptação ao ensino integral e rotina cansativa de estudos. 

## Funcionalidades
* Cadastro e perfil do estudante
* Cronogramas personalizados de estudo
* Organização de tarefas e metas
* Lembretes acadêmicos
* Acompanhamento de progresso
* Sugestões de organização utilizando inteligência artificial

## Tecnologia utilizada
O MVP será desenvolvido como uma plataforma web responsiva utilizando:
* HTML
* CSS
* JavaScript
